
# Practicar tarjetas de perfil

## Descripción
Este proyecto consiste en el desarrollo de una página web
que presenta dos tarjetas de perfil con fotografías,
descripciones y enlaces a redes sociales.

## Tecnologías utilizadas
- HTML5
- CSS3
- Font Awesome mediante CDN

## Características
- Diseño adaptable a computadores y celulares.
- Tarjetas con bordes redondeados y sombras.
- Portadas con formas diagonales usando clip-path.
- Iconos de redes sociales.
- Efectos visuales al pasar el cursor.

## Metodología BEM
Se utiliza la metodología BEM para organizar las clases CSS.

Ejemplos:
- `.perfil`: bloque principal.
- `.perfil__nombre`: elemento del bloque.
- `.perfil__portada--rosa`: modificador de la portada.
